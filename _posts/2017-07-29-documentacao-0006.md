## Dicas úteis:

* Aperte **TAB** para completar o que está escrevendo.
* **Ctrl + L** ou **clear** limpa o terminal.
* **man *comando*** acessa o manual do comando, ex: *man ls*, que também pode ser usado o *ls --help*.
* Use o **-v** junto aos comandos para que o bash imprima o que acabou de fazer.

## Quem sou? Onde estou? Como posso sair daqui?

Algo de suma importância no **Bash** do linux é saber onde está e como se mexer, segue a lista de **alguns** comandos para isso.

### Comandos de localização:

* **pwd** - Retorna no bash o caminho de onde você está.
* **cd *nome_pasta*** - Acessa o diretório nome_pasta.
* **cd** - Te leva de volta para o diretório inicial do Bash.
* **cd ..** - Volta apenas diretório para traz.

### Descobrir nosso Usuário

* **whoami** - Retorna qual usuário você está usando.

## Listagem de Arquivos / Diretórios

O comando **ls** é o comando usado pra listar, há diversas formas de usa-ló e as mais comuns são as seguintes:

* **ls** - Lista as pastas e arquivos do diretório.
* **ls *pasta_exemplo*** - Lista o que está dentro da pasta.
* **ls -l** - Lista com informações sobre os diterórios e arquivos.
* **ls -a** -  Lista com **todos os arquivos** incluindo os invisíveis.
* **ls -la** - Lista com **todos** os arq/dire com informações completas.
* **ls arq * .txt** - Lista os arquivos que começam com *arq* com o formato *.txt*. ++
* **ls * .txt** - Lista os arquivos com a extenção *.txt*. ++
* **ls** * - Lista os arquivos e diretórios e seus **primeiros** sub diretórios.

**OBS:** Como você deve ter percebido quando foi mostrado o **ls -la** é exatamente o mesmo comando que faríamos executando **ls -l -a**, o bash nos dá essa facilidade.

**++** - O  * deve ser escrito **sem espaços** da seguinte forma:

    ls arq*.txt

Mas como os **Markdowns** entraram e conflito minha opção foi escrever dessa forma, obrigado.

## Criação, Leitura e Exclusão de Arquivos / Diretórios

Para criar uma mensagem no terminal é utilizado o **echo *"Mensagem"***, que retornará logo abaixo o que acabou de escrever, mas que também pode ser usado para criar por exemplo um arquivos (Apenas para esclarecimento).

### Criação de Arquivos / Diretórios

* **echo "Olá mundo!" > ola.txt** - Cria um arquivo *.txt* escrito "Olá mundo!".
* **echo "Olá também universo" >> ola.txt** - Concatena o texto que foi passado no que já está escrito em *ola.txt*.
* **mkdir *nome_pasta*** - Cria uma pasta com o nome de *nome_pasta*.
* **mkdir *pasta/nova_pasta*** - Cria pasta dentro do diretório indicado.

### Leitura de Arquivos

Para ler um arquivo você pode por exemplo indicar um programa externo e o arquivo a ser lido, ex:

    gedit texto.txt

Dessa forma o programa abrirá o arquivo e tudo já está resolvido. Porém também é possível se ler pelo terminal, caso não possa acessar um arquivo por meio gráfico.

* **cat *arquivo.txt*** - Retorna o conteúdo do arquivo na tela.
* **cat -n *exemplo.txt*** - Retorna o conteúdo com a numeração das linhas.
* **cat * .txt** - Retorna o conteúdo de todos os arquivos *.txt* do diretório. ++
* **cat *arq??.txt*** - Retorna o conteúdo dos arquivos começados com *arq* ignorando o que está escrito em *??* com a extensão *.txt*.
* **cat *arq * .txt*** - Retorna o conteúdo dos arquivos começados com *arq* e terminados com *.txt*. ++

**++** - Sem espaços.

### Comandos para Leitura head, tail e less

* **head *arquivo.txt*** - Imprime as 10 primeiras linhas do arquivo.
* **head -n 4 *arquivo.txt*** - Imprime as 4 primeiras linhas do arquivo.

* **tail *arquivo.txt*** - Imprime as 10 últimas linhas do arquivo.
* **tail -n 4 *arquivo.txt*** - Imprime as 4 últimas linhas do arquivo.

* **less *arquivo.txt*** - Abre o arquivo no terminal, podendo se movimentar com as setas do teclado.

### Remoção de Arquivos / Diretórios

* **rm *arquivo.txt*** - Remove o arquivo selecionado.
* **rmdir *pasta_exemplo*** - Remove um diretório vazio (apenas vazios).
* **rm -r *pasta_exemplo*** - Remove recursivamente **todos** os arquivos e pastas do diretório.
* **rm -r** * - Remove o que está dentro pasta.

**Dica:** Use o **rm -rv** pois trará ao terminal o que você tudo que acabou de excluir.

## Copiar, Renomear e Mover Arquivos / Diretórios

### Copiar Arquivos / Diretórios

* **cp *arquivo.txt nome_da_copia.txt*** - Copia o *arquivo.txt* para *nome_da_copia.txt*.
* **cp -r *nome_pasta copia_pasta*** - Copia a *nome_pasta* como *copia_pasta*.

### Renomeando e Movendo arquivos

Caso **não exista** um diretório com o mesmo nome que esta indicando para o **mv** você estará alterando o nome da sua pasta.

* **mv *nome_antigo.txt nome_novo.txt*** - Modifica o nome do arquivo, para o novo indicado.
* **mv *nome_pasta nome_novo_pasta*** - Muda o nome da pasta para o outro indicado.

**Caso** uma pasta com o mesmo nome da que você está tentando mudar já exita, o **mv** moverá as pastas e os arquivos para dentro dessa que já existe.

* **mv *arquivo.txt pasta_exemplo*** - Move o *arquivo.txt* para dentro da *pasta_exemplo*.
* **mv *pasta_exemplo uma_pasta_existente*** - Move a *pasta_exemplo* para dentro de *uma_pasta_existente*.


## Compactação

Podemos compactar também os arquivos pelo terminal, em formatos como por exemplpo em *.zip* ou *.tar.gz*.

### Compactar em .zip

* **zip *arquivo.zip documento.txt*** - Cria *arquivo.zip* com o coteúdo de *documento.txt* compactado.
* **zip *work.zip workspace*** - Cria *work.zip* com apenas a pasta *workspace*, os arquivo dentro dela são ignorados.
* **zip -r *work.zip workspace*** - Cria *work.zip* com *todos* os arquivos da pasta *workspace*.

Para se ler o que está dentro de um *.zip* se usa os seguinte comando:

* **unzip -l *arquivo.zip*** - Traz uma lista do que está dentro do *.zip*.

Para descompactar o *.zip* é só fazer:

* **unzip *arquivo.zip***

**Dica:** Caso queira calar o zip (que ele não imprima o que está fazendo dentro do terminal), use o *-q* que calará a ação.

* **unzip -q *arquivo.zip***

### Compactar em tar.gz

Quando você usar o **tar** estará empacotando um arquivo e depois irá compacta-lo em *.gz* (.gzip) por exemplo.

* **tar -cz *workspace > workspace.tar.gz*** - Você manda o *tar* **-c** (criar) um **-z** (compactação) com a pasta *workspace* em *workspace.tar.gz*.
* **tar -xz < *workspace.tar.gz*** - Você extrai o que está dentro do *.workspace.tar.gz*

Mas é possível simplificar:

* **tar -czf *workspace.tar.gz workspace*** - Onde indica que quer criar um arquivo compactado em *.tar.gz* da pasta *workspace*.
* **tar -xf *arquivo.tar.gz*** - Onde extrai o arquivo. ++

**OBS:** O **-f** indica que trataremos um arquivo.

**++:** O **-z** foi omitido pois é opcional.

### Compactar em tar.bz2

O **tar** também pode compactar em **.bz2** (.bzip2) que é mais eficiente na compactação porem mais demorado. A única diferênça é a troca do **-z** pelo **-j**.

* **tar -cjf *workspace.tar.bz2 workspace*** - Cria arquivo compactado em *.tar.bz2* da pasta *workspace*.
* **tar -xj *arquivo.tar.bz2*** - Extrai o arquivo.
