MySQL é um sistema de gerenciamento banco de dados que utiliza a linguagem **SQL**, a sintaxe é bastante simples e se aproxima bastante do **inglês**, oque facilita bastante o aprendizado.

### Nunca se esqueça:

* De usar o ';' no final de **todos** os comandos que fizer dentro do **MySQL**.


## Criando Bancos de Dados e Tabelas

A lógica segue a mesma para se criar os dois tipos de agrupamentos, seguindo o exemplo:

    // Na sequência:
    ação oque_está_criando nome_que_será_atribuído;

### Criando Bancos de Dados

Então para se **criar** um banco de dados se faz:

    create database dados_facr;

E para **usa-lo** e posteriormente se criar uma tabela ou fazer o que bem quiser:

    use dados_facr;

### Criando Tabelas

Se segue a mesma estrutura de antes, porem com algumas diferênças:

    create table carteira(
      id int auto_increment primary key,
      transacao varchar(3),
      valor double,
      no_banco boolean
    );

O nome da tabela é seguido por **()** contendo os nomes das colunas que irão ser criadas seguidas pelos seus tipos de dados e características **divididas** por vírgulas.

    nome_tabela(
      nome_coluna tipo_de_dados ~características~;
    );

**OBS:** O comando **auto_increment** diz para o sistema que o valor deve ser incrementado automaticamente e **primary key** diz que o valor será usado como **chave primária** de consulta, ou seja, um **identificador de cada linha** adicionada.

Para se **visualizar as características** da tabela usa-se o comando:

    desc carteira;

    // Retornando:
    +-----------+--------------+------+-----+---------+----------------+
    | Field     | Type         | Null | Key | Default | Extra          |
    +-----------+--------------+------+-----+---------+----------------+
    | id        | int(11)      | NO   | PRI | NULL    | auto_increment |
    | transacao | varchar(3)   | YES  |     | NULL    |                |
    | valor     | double       | YES  |     | NULL    |                |
    | no_banco  | tinyint(1)   | YES  |     | NULL    |                |
    +-----------+--------------+------+-----+---------+----------------+

**OBS:** A tabela acima não terá uma **boa aparência** se não for visualizada em um computador. ;D

## Visualizando Bancos de Dados e Tabelas

Para se visualizar bancos de dados:

    show databases;

    // Retornando:
    +---------------------+
    | Database            |
    +---------------------+
    | information_schema  |
    | dados_facr          |
    | mysql               |
    | performance_schema  |
    | sys                 |
    +---------------------+

E para visualizar tabelas:

    // Primeiro é necessário se "usar" um banco de dados
    use dados_facr;

    // E então visualizar:
    show tables;

    // Retornando:
    +----------------------+
    | Tables_in_dados_facr |
    +----------------------+
    | carteira             |
    +----------------------+

## Inserindo linhas em Tabelas

Se segue a lógica:

    inserir dentro_de nome_da_tabela (nome_da_coluna) valores (valor);

    // Seguindo o caminho criado nessa documentação:
    insert into carteira(
      transacao, valor, no_banco
    )
    values (
      deb, 1585.45, 1
    );

    // Se quiser visualizar as linhas da tabela:
    select * from carteira;

    // Retornará:
    +----+-----------+---------+----------+
    | id | transacao | valor   | no_banco |
    +----+-----------+---------+----------+
    |  1 | deb       | 1585.45 |        1 |
    +----+-----------+---------+----------+

Caso queira adicionar mais de uma linha a tabela passe os valores separados por virgulas e parênteses:

    values
      (deb, 1800.00, 1),
      (dep, 6820.50, 1)
    ;

    // Com o retorno:
    +----+-----------+---------+----------+
    | id | transacao | valor   | no_banco |
    +----+-----------+---------+----------+
    |  1 | deb       | 1585.45 |        1 |
    |  2 | deb       | 1800.00 |        1 |
    |  3 | dep       | 6820.50 |        1 |
    +----+-----------+---------+----------+
