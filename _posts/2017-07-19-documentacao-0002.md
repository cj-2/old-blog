## Seleções no DOM

Diferente do JavaScript puro que se tem diversas formas de se capturar um objeto no DOM, no jQuery é **mais enxuto**
(de acordo com o que já estudei) e mais simples, por exemplo para se selecionar uma div pelo id:

    // No JS seria feito assim:
    var exemplo = document.querySelector('#id_div');

    // Equanto que no jQuery se resume há:
    var exemplo = jQuery('#id_div');

    // Ou para os mais íntimos:
    var exemplo = $('#id_div');

As funções **jQuery()** e **$()** fazem **exatamente a mesma ação**, porem uma é uma abreviação da outra.

## Editando o DOM com text() e val()

Caso queira capturar valores do html ou de algum input é usado as variáveis **text()** e **val()**, onde text() devolve o texto e val() o valor.

Como segue os exemplos:

    // Para capturarmos o texto de dentro da tag:
    <p class="paragrafo">Olá!</p>

    // Faremos da seguinte forma:
    var paragrafo = $('.paragrafo').text();

    // Em que console.log(paragrafo);
    // Imprimirá a string: Olá!

Seguindo a mesma lógica, **val()** faz o mesmo:

    // Para capturarmos o valor do input:
    <input type="text" class="numeros">

    // Faremos da mesma forma:
    var paragrafo = $('.numeros').val();

    // Caso impresso também irá ter o mesmo conteúdo.

O mais interessante é que as mesmas funções também podem ser usadas **para editar** o texto e o valores dos objetos referentes.

    // Seguindo os exemplos acima
    paragrafo.text('Uma String diferente.');
    numeros.val('4321');

Irão alterar o DOM.
