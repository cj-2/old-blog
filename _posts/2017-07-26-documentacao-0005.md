## Coemçando um código

Para se escrever qualquer coisa em php é necessário se abri e fechar a tag <? php, por exemplo:

    <?php
      $nome   = 'Carlos';
      $idade  =     '19';
      $casado =    false;

      if($casado) $civil =   'é';
      else        $civil = 'não';
    ?>

    // HTML:
    <p>
      O cliente <?php echo $nome ?>
      possui <?php echo $idade ?>
      anos de idade e
      <?php echo $civil ?> casado.
    <p>

    // Que terá a saída
    O cliente Carlos possui 19 anos de idade e não é casado.

Porem caso contenha **apenas php**, ou seja, apenas pra determinada ação a tag <? php **não necessita** ser fechada.

    <?php
      echo 'Não preciso ser fechada!';

Mas podemos **melhorar** ainda mais a parte em HTML do primeiro código, por exemplo trocando o **<? php echo $exemplo** por apenas **<? = $exemplo** que executa a mesma ação, ou seja, imprime a variável no DOM.

    <p>
      O cliente <?= $nome ?>
      possui <?= $idade ?>
      anos de idade e
      <?= $civil ?> casado.
    <p>

Sempre deixar seu código mais **simples** e  de **fácil leitura** é fundamental para se programar bem.

**OBS:** O encurtador de tags do php < ?= só funciona a partir do php 5.4 para frente (Mas é possível a ativação em versões mais antigas... **PESQUISE COMO!**).

## Sintaxe básica

A Sintaxe do php não difere muito de outras linguagens de programação e também é bastante simples.

<a name="criando-variaveis-php" />

### Criando variáveis

Para se criar uma váriavel é necessário apenas usar o **$** seguido do nome da variável.

    // Exemplos simples:
    $numeral =    15;
    $string  = 'Olá';

    // Booleanos:
    $boo =  false;  // Falso
    $boo =      0;  // Falso
    $boo =     "";  // Falso
    $boo =   true;  // Verdadeiro
    $boo =      1;  // Verdadeiro
    $boo =     -1;  // Verdadeiro

    // Arrays:
    $array = array(1, 2, 3);
    $array =      [1, 2, 3];

**OBS:** Os dados booleanos são case-insensitive ou seja TRUE e true dão na mesma.

Os **arrays** possuem duas formas disitíntas de serem criadas, pela *"função"* **array()** ou simplesmente atribuindo os colchetes a variável, exemplo: **$boo = [ ];**

<a name="concatenacao-php" />

### Concatenação

Para se concatenar diferente de outras linguagens de programação é usado o ponto '.' e não o mais '+' como por exemplo em JavaScript, veja o exemplo:

    // Apresentando um produto
    <?php
      $nomeP = 'Boneca';
      $preco =    19.90;

      $string = 'Você selecionou um(a) ' . $nomeP . ' de ' . $preco . ' R$.';
      echo $string;

    // Saída:
    Você selecionou um(a) Boneca de 19.9 R$.

Ou para simplificar (como de prática), podemos utiliza a sintaxe {$variavel} evitando assim tantas concatenações.

    $string = "Você selecionou um(a) {$nomeP} de {$preco} R$.";

**OBS:** É necessário usar as aspas duplas "" quando usar a sintaxe {$variavel} ou não funcionará corretamente.

<a name="criando-uma-funcao-php" />

### Criando uma Função

Quase exatamente da forma que se é criado no JS:

    <?php
      function fun($dado_1, $dado_2){
        return $dado_1 + $dado_2;
      }
      echo fun(20, 15);

    // Saída: 35

Porem os **nomes dos parâmetros** recebidos devem ser escritos com **$** na frente.

<a name="substituindo-colchetes-php" />

### Substuição dos colchetes "{ }"

É possível se substituir os colchetes por outra estrutura de escrita mais verbosa.

    foreach($produtos as $produto) :
      echo $produto['nome'];
    endforeach;

Essa estrutura é bastante útil **quando** se é usado o PHP junto com HTML.

## Arrays

Como já mostrado acima, um array pode ser criado de duas formas, pela função **array()** ou atribuindo um **[]** a variável.

<a name="manipulacao-basica-de-arrays-php" />

### Manipulação básica de Arrays

Para relembrar, podemos criar arrays das seguintes formas:

    <?php
      $array_1 = array(1, 2, 3);
      $array_2 =      [1, 2, 3];


Podemos também atribuir chaves e valores:

    <?php
      $exemplo = [
        'primeiro' => 'Biscoitos';
        'segundo'  =>      'Olá!';
      ];

Que caso impressos por um **foreach()** retornarão os valores, que no exemplo acima serão: Biscoitos e Olá.

Caso queira **adicionar algum** valor a alguma array, faça:

      <?php
        $arr   =      [];
        $arr[] = 'Facão';

Caso queira criar um chave para seu valor adicionado, faça:

      <?php
        $arr['chave_1'] = 'Segredos';


Os arrays também possuem várias funções de tratamento, por exemplo para se testar se um valor existe ou o tamanho...
Uma infinidade de funções que abordaremos em seguida (algumas das mais usadas).

<a name="funcoes-relacionadas-aos-arrays-php" />

### Funções relacionadas aos Arrays

* **sizeof($array_name)** - Retorna a quantidade de itens o array possui.
* **array_push($array, $item)** - Adiciona um item ao array.
* **in_array('valor', $array)** - Verifica se um valor existe em uma array.
* **array_key_exists('chave', $array)** - Verifica se uma chave ou índice existe em um array.

### Exemplos de funções relacionadas aos Arrays

#### sizeof()

    <?php
      $array = ['Olá' , 42, 'Chocolate', 'Marvin'];
      echo sizeof($array);

      // Retorna: 4

#### array_push()

    <?php
      $array =       [];
      $item  = 'Banana';

      array_push($array, $item);
      echo $array[0];

      // Retorna: Banana

#### in_array()

    <?php
      $fruteira = ['Banana', 'Laranja', 'Mamão'];
      $fruta    =                         'Maçã';

      array_push($fruteira, $fruta);

      if(in_array('Maçã', $fruteira))
        echo 'Há sua fruta preferida na fruteira!';
      else
        echo 'Parece que alguém comeu sua fruta preferida...';

#### array_key_exists()

      <?php
        $moch = ['Pão' => 'Comer'];

        if(array_key_exists('Pão', $moch))
          echo 'Tem pão em sua mochila!';
        else
          echo 'Parece que alguém comeu tudo...';

## Banco de Dados: MySQL

Algumas funções básicas de contato com banco de dados MySQL.

<a name="funcoes-mysql-php" />

### Funções MySQL

* **mysqli_connect($host_name, $user, $senha_user, $base_name)** - Cria uma conexão com o banco de dados com o usuário e o host indicado.
* **mysqli_query($conexao, $query)** - Carrega uma conexão e executa uma query("Comandos").
* **mysqli_fetch_assoc($resultado_query)** - Retorna a primeira linha do resultado de uma query.

#### Apuração de erros:

* **mysqli_connect_error()** - Retorna o erro da conexão caso exista algum.

### Exemplos de funções MySQL

#### mysqli_connect()

    <?php
      $host_name = 'localhost';
      $user = 'root';
      $senha_user = 'um_grande_segredo';
      $base_name = 'banco_exemplo';

      $conexao = mysqli_connect(
        $host_name, $user, $senha_user, $base_name
      );

#### mysqli_connect_error()

    <?php
      if ($erro = mysqli_connect_error()){
        echo $erro;
      }

#### mysqli_query()

    <?php
      $query = "select * from tabela_exemplo;";

      $consulta = mysqli_query($conexao, $query);

#### mysqli_fetch_assoc()

    <?php
      $lista = [];

      while($item_lista = mysqli_fetch_assoc($consulta)){
        array_push($lista, $item_lista);
      }
